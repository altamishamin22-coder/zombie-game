# Zombie Smash

A thrilling zombie survival game where players fight against endless waves of zombies, test their skills, and survive in a dangerous world filled with action and challenges.

## 🎮 About The Game

**Zombie Smash** is an action-packed survival experience designed to bring fast combat, exciting gameplay, and a fun zombie-killing adventure.

Players must defeat waves of zombies, improve their skills, and survive as long as possible while facing increasing challenges.

## ✨ Features

- 🧟 Zombie wave survival gameplay
- ⚔️ Fast-paced combat system
- 🎯 Challenging enemies
- 💥 Action-focused gameplay
- 🏆 Score-based progression
- 🎮 Smooth and responsive controls
- 🌎 Immersive zombie environment
- 🚀 Optimized performance

## 🕹️ Gameplay

- Fight against incoming zombie attacks
- Survive as many waves as possible
- Earn points by defeating enemies
- Improve your strategy and skills
- Become the ultimate zombie survivor

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Modern Web Technologies

## 🚀 Installation & Running Locally

Clone the repository:

```bash
git clone https://github.com/yourusername/zombie-smash.git
```

Open the project folder:

```bash
cd zombie-smash
```

Run the project using Live Server or open:

```
index.html
```

in your browser.
